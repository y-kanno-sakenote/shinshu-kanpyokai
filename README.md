# 全国新酒鑑評会 入賞酒の記録

独立行政法人酒類総合研究所（平成18酒造年度以降は日本酒造組合中央会と連名）が公表している「全国新酒鑑評会 入賞酒目録」（平成14〜令和7酒造年度、24年度分・10,668点）を、地図・年度推移・製造場の累計・検索で見られるようにした非公式の可視化です。

- 見る: https://y-kanno-sakenote.github.io/shinshu-kanpyokai/

## データについて

- 出典: 酒類総合研究所「全国新酒鑑評会 審査結果について」 https://www.nrib.go.jp/data/kan/shinshu/award/ の各年度の入賞酒目録（PDF）と審査結果ページ
- 製造場名・商標名は目録の表記のままです。各年度の入賞点数・金賞点数は審査結果ページの数字と一致することを確かめています
- 令和元酒造年度は、審査結果ページに「金賞酒は、決審中止に伴い選定いたしませんでした。」とあります
- 本ページで足したのは、年度をまたいで同じ製造場をまとめる名寄せだけです（同じ都道府県で、表記の揺れ・法人番号の一致・国税庁法人番号公表サイトの変更履歴で同一と確かめたもの。同名の別法人1件は法人番号のない年度を銘柄で振り分け）。地図は都道府県単位です
- 作成: 合同会社サケノテ（sakenote.net）。酒類総合研究所・日本酒造組合中央会の公式サイトではありません
